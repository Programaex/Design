# Executar App — Scroll Task HTML Prototype

Protótipo navegável e autocontido da funcionalidade **Scroll Task**.

## Abrir

1. Descompacte o ZIP.
2. Abra `index.html` em Chrome, Safari, Edge ou Firefox.
3. Não requer servidor, dependências, build ou conexão com internet.

## Interações implementadas

- execução por ação, tarefa, fase ou workflow;
- timer de 15/30/45 minutos e 10 s para demonstração;
- iniciar, pausar e reiniciar timer;
- Auto-scroll ao terminar o timer;
- navegação por swipe vertical, roda do mouse, botões e setas ↑/↓;
- duplo clique/toque equivalente pelo botão “Contexto”;
- nota por item;
- concluir/desfazer conclusão;
- contador de itens pendentes;
- estado visual do item concluído.

## Arquivos

- `index.html`: protótipo funcional.
- `INSTRUCOES_DESENVOLVIMENTO.md`: contrato de implementação.
- `data/example-project.json`: modelo mínimo de dados.

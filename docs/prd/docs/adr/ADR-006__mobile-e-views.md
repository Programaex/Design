# ADR-006 — Web responsiva primeiro, orientação independente

Status: Proposta. Data: 2026-10-16.

## Contexto
Usuário quer web/mobile em diferentes orientações.

## Decisão proposta
Primeiro garantir a mesma funcionalidade na web móvel; oferecer LR/TB/bilateral sem depender de rotação do aparelho. Definir depois se haverá wrapper/native.

## Alternativas
Duas implementações imediatas duplicam lógica antes de estabilizar os contratos.

## Consequências
Não satisfaz por si só requisito de app nativo, caso este seja confirmado.

## Validação
Ver FRD e handoff/ACEITE.md. Nenhum ADR foi tratado como decisão aprovada pelo usuário além dos requisitos expressamente pedidos.

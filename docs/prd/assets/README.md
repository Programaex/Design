# Referências
Nomes seguem `ID__descricao.ext`. O MASTER_INDEX.csv é a autoridade para nome original, destino, função, dimensões e SHA-256. Renomear não altera bytes. Os horários nos nomes são apenas os visíveis nas capturas, sem inferir fuso. Referências não são componentes prontos nem prova de licença para redistribuição pública. Usar como direção interna de layout; marcas e dados de exemplo não viram conteúdo do produto.

REF-004/005 são o par de grafo recolhido/expandido. REF-006–011 são estados do stepper, não seis tarefas obrigatórias. REF-012 é progresso/log. REF-018 é secundária. “Triped Envelope” não foi encontrado como arquivo ou rótulo inequívoco; DOC-003 e REF-019 cobrem o calendário light mode, sem presumir equivalência.

Abra `../REFERENCIAS.html` para consultar as imagens com nomes e descrições.

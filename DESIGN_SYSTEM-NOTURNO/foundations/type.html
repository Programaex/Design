Usage

Headings take var(--font-heading) at var(--font-heading-weight) automatically; body copy inherits var(--font-body). Tracking is negative (−0.022em on body) — it is what makes the type read as one tight mass. The stack opens with -apple-system, which is SF Pro on every Apple device; elsewhere Inter loads from Google Fonts. SF Pro itself is licensed by Apple for Apple-platform work, so it is named in the stack but not bundled. Never name a font family directly.

# EXECUTAR — pacote para Claude Design

1. Leia `ADR-001-arquitetura-blocos.md`.
2. Envie `CLAUDE_DESIGN_PROMPT.md` ao Claude Design com os arquivos deste pacote.
3. Use `referencias/*_full.png` como referências visuais reais e `public/placeholders/*.svg` como imagens do protótipo.
4. Importe `EXECUTAR_rotas.csv` e confira `route-blueprints.json` para famílias, receitas e arquivos de página.

## Conteúdo

- ADR: decisões de arquitetura, navegação, UI, blocos, CMS e aceite.
- Prompt: instrução pronta para execução.
- CSV: 78 entradas originais, preservadas.
- Blueprints JSON: mapeamento complementar de cada entrada para layout e blocos.
- Registry JSON: blocos e propriedades esperadas.
- Page examples JSON: composições iniciais demonstrativas.
- SVGs: seis placeholders locais.
- Referências PNG: três capturas desktop de página inteira e visão conjunta.
- Manifesto de capturas: origem, método, dimensões e limitações.

O pacote especifica a construção. Não é uma aplicação implementada ou um clone já publicado. Capturas são evidências das referências; placeholders são os ativos a usar no EXECUTAR. A captura do artigo foi composta por trechos sobrepostos devido ao timeout da captura única. As capturas de referência não comprovam comportamento mobile, backend ou estados de carrosséis não selecionados.
